# 📊 Campus Placement Intelligence Dashboard (Excel)

An interactive Microsoft Excel dashboard developed to analyze campus placement eligibility based on company-specific requirements. This project automates eligibility evaluation, provides dynamic dashboards, enables student search, and offers interactive placement analysis using Pivot Tables, Pivot Charts, and Slicers.

---

## 📌 Project Overview

The Campus Placement Intelligence Dashboard is designed to help Training & Placement Officers (TPOs) quickly determine which students are eligible for campus recruitment drives.

The dashboard automatically compares student details with company eligibility criteria such as:

- Minimum CGPA
- Maximum Backlogs
- Required Skills
- Package Offered (LPA)

It provides an interactive dashboard, eligibility engine, student search functionality, and placement analytics.

---

## 🚀 Features

### ✅ Interactive Dashboard
- Company-wise eligibility analysis
- Total Students KPI
- Eligible Students KPI
- Not Eligible Students KPI
- Eligibility Percentage KPI
- Pie Chart for Eligibility Distribution
- Column Chart for Placement Eligibility

### ✅ Eligibility Engine
- Company Selection using Drop-down
- Automatic Company Requirement Lookup
- Dynamic Eligibility Calculation
- Eligibility Reason Generation

### ✅ Student Search
- Search student details using Student ID
- Displays:
  - Student Name
  - Degree
  - CGPA
  - Backlogs
  - Skills
  - Eligibility Status
  - Reason

### ✅ Pivot Analysis
- Placement Status Summary
- Company-wise Placement Summary
- Pivot Charts
- Interactive Slicers
  - Degree
  - Specialization
  - Placement Status

### ✅ Student Master Database
Contains complete student information including:
- Student ID
- Student Name
- Degree
- Specialization
- CGPA
- 10th Percentage
- 12th Percentage
- Active Backlogs
- Skills
- Placement Status
- Company Placed
- Package (LPA)
- Overall Rank
- Placement Chance

### ✅ Company Requirements Database
Stores company eligibility criteria:
- Company Name
- Minimum CGPA
- Maximum Backlogs
- Required Skill
- Package Offered
